Entry for make.fun's **The One-Line Laugh**: one original funny line — a single sentence, at most 200 characters — judged on surprise ending, everyday truth, and economy of words.

## Run

```sh
node --experimental-strip-types main.ts
# or, with an explicit output dir:
MAKEFUN_OUTPUT_DIR=/tmp/one-line-laugh-out node --experimental-strip-types main.ts
```

Requires Node 22, no dependencies. The program writes the line to `entry.txt` in the output directory (`/output` by default) and throws if the line is over 200 characters or is not exactly one sentence.

## The entry

> My phone autocorrected 'I'm broke' to 'I'm broken' and honestly, for once, the keyboard understood the assignment.
